Windows setup guide

Pega QA
Job Digest

Configure LinkedIn job alerts, connect an Outlook mailbox, and schedule a new-jobs-only digest for 10:00 PM each day.

What this utility does
Reads LinkedIn alert emails from Outlook, filters for Pega QA Engineer roles, and emails job links for you to review. It does not scrape LinkedIn or submit applications.

1 Create a LinkedIn alert

  1. Open LinkedIn Jobs and search for Pega QA Engineer.
  2. Choose your preferred location and any other search filters.
  3. Turn on the job alert, then open Manage alerts.
  4. Set frequency to Daily and delivery to Email. Send it to the Outlook inbox this utility will read.

How the role filter works

  • Requires Pega and a QA, quality assurance, or test-engineer title.
  • Includes a listing as a match when its alert text explicitly describes basic or limited automation experience.
  • Excludes clear automation-heavy requirements. Unclear requirements go into a review section.
New jobs: the first run checks alerts received in the previous 24 hours. Later runs check since the last successful digest and skip job links already emailed. LinkedIn alerts may omit the original posting date, so “new” means a previously unseen link, not a verified posting date.

Account connection

2. Register the Microsoft app

  1. Open entra.microsoft.com and select App registrations > New registration.
  2. Name it Pega QA Job Digest. For an Outlook.com account, select Accounts in any organizational directory and personal Microsoft accounts. For a work account, choose the account type required by your organization.
  3. After registration, open Authentication > Advanced settings, set Allow public client flows to Yes, and save.
  4. Open API permissions > Add a permission > Microsoft Graph > Delegated permissions. Add Mail.Read and Mail.Send.
  5. Copy the Application (client) ID from the app's Overview page. No client secret is needed.
Permission scope: choose Delegated permissions, not Application permissions. The utility reads and sends mail as the signed-in Outlook user. An organization may require an administrator to grant consent.

3 Configure the utility

Open PowerShell in the repository folder and run:

cd .\job-digest npm install Copy-Item .env.example .env

Open job-digest\.env and set these values:

MS_CLIENT_ID=your-application-client-id MS_TENANT_ID=common DIGEST_EMAIL=your-outlook-address

Use the Outlook address that receives the LinkedIn alerts for DIGEST_EMAIL. Keep .env on your computer; it is ignored by Git.

Install-script note

If npm says it blocked the keytar install script, run:

npm install-scripts approve keytar npm rebuild keytar
Microsoft authentication uses a device code and a Windows DPAPI-protected token cache.
First run and schedule

4. Sign in and schedule 10 PM

From the job-digest folder, run:

npm test npm start

On the first run, the terminal displays a Microsoft sign-in code and instructions. Open the displayed verification page, enter the code, and sign in with the Outlook account that receives the LinkedIn alerts. Approve the requested mail permissions.

5 Register the daily task

After npm start completes successfully, run this from the job-digest folder:

.\register-task.ps1

This registers a Windows Task Scheduler job for 10:00 PM local time every day, using the current Windows account.

  • The PC must be awake and that Windows user logged in at 10 PM.
  • Run it as the same Windows user who completed device-code sign-in.
  • The task sends a no-new-jobs message when every link has already been shown.

Previously sent jobs

The digest records links it has emailed in %LOCALAPPDATA%\PegaQaJobDigest\job-state.json. Each successful run advances the time window, so later digests do not repeat the same job link.

Quick troubleshooting

ProblemCheck
Missing configurationConfirm .env contains MS_CLIENT_ID and DIGEST_EMAIL.
Permission or consent errorConfirm delegated Mail.Read and Mail.Send were added; ask your organization admin if required.
No matching jobsConfirm the LinkedIn alert is daily, emailed to this inbox, and the utility is signed into that same account.
Task did not runCheck that the PC was awake and the same Windows user was logged in at 10 PM.
The digest provides links for your review; it does not automatically apply for jobs.
